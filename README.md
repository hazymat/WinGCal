# WinGCal

Google Calendar on your Windows desktop: a glass calendar widget that stays on the desktop, and remembers where it goes on each monitor setup.

- Month, week and agenda layouts that follow the window's size
- One or more Google accounts; pick which calendars show, with a quick switcher in the window
- Pin it to the desktop (still there after Win+D), or unpin it to move and resize it
- Remembers its place, size and scale for every combination of monitors
- Full JSON export of every event, for backup

Same family as [WinSqueeze](https://github.com/hazymat/winsqueeze) and [WinTapeRecorder](https://github.com/hazymat/wintaperecorder). Free software under the GNU GPL v3.
